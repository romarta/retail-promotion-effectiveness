# Data Source

**Dataset:** dunnhumby — The Complete Journey  
**Source:** https://www.dunnhumby.com/source-files/

The dataset contains approximately two years of transaction history for 2,500 households, along with product, demographic, and promotional campaign data.

## Dataset Files

| File | Description |
|---|---|
| `transaction_data.csv` | Household purchases and transaction details |
| `product.csv` | Product attributes and categories |
| `hh_demographic.csv` | Household demographic classifications |
| `campaign_desc.csv` | Campaign types and durations |
| `campaign_table.csv` | Household campaign participation |
| `coupon.csv` | Campaign coupons and eligible products |
| `coupon_redempt.csv` | Coupon redemption records |
| `causal_data.csv` | In-store displays and promotional mailer placements |

## Data Storage

Original CSV files are stored locally in `data/raw/` and excluded from GitHub via `.gitignore`.

Data is used without modifying the original source files.
